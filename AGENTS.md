# AZLO site — Instruções para agentes

- Leia `README.md` e `package.json` antes de editar.
- Preserve mudanças locais não commitadas; não use `git reset`, `git clean`, checkout forçado ou reinstalações destrutivas sem ordem explícita.
- Comandos: `npm run dev`, `npm run lint`, `npm run build`.
- `node_modules/`, `.next/` e `out/` são gerados; não os edite manualmente.
- Execute lint antes de concluir alterações de código. Build somente quando necessário, pois gera artefatos.
